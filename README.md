## 배포

GitHub Pages의 게시 원본은 `main` 브랜치의 `/ (root)`입니다. 루트 파일을 변경하면 자동 배포됩니다. `.nojekyll`로 정적 HTML을 그대로 제공합니다.

## 자료 기준

제공받은 이론완성노트와 2026 빈출 문제풀이집을 바탕으로 재구성한 개인 학습자료입니다. 원본 PDF는 이 저장소에 포함하지 않으며 각 항목에 원본 페이지를 표시했습니다. 법규·세제는 원자료 기준이며 실제 시험 기준과 개정사항은 별도로 확인해야 합니다.

풀이기록은 각 브라우저의 localStorage에 저장됩니다. 브라우저·사이트 주소가 바뀌면 기존 로컬 파일의 기록과 공유되지 않습니다.
